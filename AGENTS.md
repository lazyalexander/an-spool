# an-spool contributor contract

This repository owns mature domain packages, not a runtime or model loop.
Keep source, knowledge, skills, instructions and domain tests with each spool.
Use an-loom for validation/packaging and the existing an-agent APIs for execution.
Do not introduce a parallel host, scheduler, provider client or credential store.

English code comments and documentation are authoritative. Conversation follows
the user. Preserve upstream licenses and exact migration provenance.

Release baselines are immutable silk. Runtime edits/new work are kit and remain
in host-managed instances. Runtime instructions remain protected; labels never
create execution or disclosure grants. Accepted artifacts have separate custody.

Keep current development on dev-advance. Publish only reviewed public source,
portable summaries and immutable distributions. Do not include credentials,
absolute operator paths, native transcripts or private acceptance records.
Main promotion remains a user-reviewed decision. Do not rewrite old releases.

Before committing a package change, run its domain tests, Loom verify, client
reproduction check and applicable real CAD→Krita acceptance. A packaging check is
not a runtime qualification. Preserve strict assertions and report unknown outcomes.
