# CAD material policy

Domain instructions, completion schemas, literal appearance-kit generation and
single-read historical-material adoption live here. Shuttle supplies the approved
harness transport, evidence reader and cancellation signal. The host owns grants,
execution and accepted-artifact custody. This package creates no process or service.

The renderer remains the immutable `@an-loom/cad-paint-spool` 0.1.0 release.
This separately versioned client policy preserves that release identity. Changing
policy requires a new reviewed client version; old distributions stay immutable.

Run `npm ci --ignore-scripts`, `npm run build`, and `npm test`. Published clients
contain compiled policy and this guide, never runtime profiles or credentials.
