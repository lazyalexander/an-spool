# Document domain instructions

Preserve source item names, quantities, decimal EUR prices and accepted Markdown
identity. Missing currency or quantities require clarification. Never invent rows
or relax verification to pass a model proposal. The v1 source format is bounded
text PDF line-item quotes, not arbitrary PDFs, OCR or general spreadsheets.

The host owns authority, cancellation, lifecycle and artifact custody. The domain
body performs extraction, workbook authoring and independent output checks only.
It must not contain a provider client, harness protocol, host credential or network
installer. New/modified work is kit; published baselines are immutable silk.
