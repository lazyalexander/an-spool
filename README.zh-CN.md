# an-spool

集中维护已验收的领域 spool：源码、知识、技能、指令、业务测试与固定版本发布包。

首个包位于 `spools/cad-paint`。本轮在 macOS 上通过真实 Codex 补材质、原生
绘制、host 产物验收和 Krita 回存；台钳四层、手轮五层均可编辑，像素严格一致。
异常输入与取消任务没有交付产物。具体发布身份见 `catalog.json`。

an-loom 负责开发、验证和打包；an-agent 负责守护、调度、权限、执行和产物托管；
an-shuttle 负责 CAD/Krita 应用桥接。本仓库不增加运行器、调度器或模型循环。

发布基线保持为 silk；运行修改与新增内容标为 kit，由 host 管理。运行实例、
凭据、模型原始事件与用户绘画不进入本仓库。首次迁移保留历史 npm 名称、版本、
发布包与 runtime/profile 身份；新的开发修改须产生新的审阅版本。
